# Content

Your `eponyme.config.ts` describes what the site holds. Everything on this page follows from that one
file: the controls the dashboard renders, the validation the server enforces, and the types your pages
read.

Three shapes exist at the top level of a config:

```ts [eponyme.config.ts]
export default defineEponymeConfig({
  // a singleton: one entry, edited in place
  homepage: {
    title: field.string({ required: true }),
  },

  // a collection: repeatable entries with their own slugs
  articles: collection({
    titleField: 'title',
    slugField: 'slug',
    fields: {
      title: field.string({ required: true }),
      slug: field.slug({ required: true }),
    },
  }),

  // a form: a public schema with its own submissions
  contact: form({
    fields: {
      email: field.email({ required: true }),
    },
  }),
})
```

A plain object is a singleton. Nest objects to group entries under a folder, and the dashboard mirrors
that nesting in its navigation:

```ts
pages: {
  legal: {
    terms: { body: field.richText() },
    privacy: { body: field.richText() },
  },
}
```

That declares `pages/legal/terms` and `pages/legal/privacy`.
