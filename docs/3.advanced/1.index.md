# Advanced

Everything here is optional. A site works without any of it. These are the seams to reach for once
content is flowing and you start caring about how fast it is served, what happens around a write, and
how content moves between environments.

## Caching

The three windows Eponyme sets on its own, the tags it attaches so a CDN can be purged by
publication, and how to make a whole page cacheable without prebuilding anything.

:read-more{to="/advanced/caching"}

## Server hooks

Nitro hooks around every content write and every form submission. A blocking hook can refuse or amend
a write. A notification hook can purge a CDN, ping a webhook or send a message.

:read-more{to="/advanced/hooks"}

## Sitemap

One public route listing every URL Eponyme knows about, plus the typed server utility behind it so a
sitemap integration needs no internal HTTP request.

:read-more{to="/advanced/sitemap"}

## Export and import

Move content prepared on one environment to another, guarded by a schema fingerprint that refuses the
whole import rather than writing something half-compatible.

:read-more{to="/advanced/export-import"}

## Dashboard language

Replace the English interface with another language, resolved once at build time and shared by the
browser and the server.

:read-more{to="/advanced/locale"}

## File storage

Uploads, the media library and what `field.file()` writes into. Off until you configure it, and
while it is off none of it is registered.

:read-more{to="/advanced/storage"}

## Editorial lifecycle

Publish, unpublish, return content to draft, or schedule either transition down to the minute.
Public reads remain correct even when no scheduler is running.

:read-more{to="/advanced/editorial-lifecycle"}

## Roles, permissions and audit

Add application-owned roles, scope their rights to exact resources or folders, and inspect the
owner-only security and editorial audit log.

:read-more{to="/advanced/permissions-audit"}
