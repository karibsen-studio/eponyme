# Sitemap

Every URL Eponyme knows about comes from `previewPaths`, so declaring a public route once is enough
to list it.

One lightweight public route lists every URL Eponyme knows about:

```
GET /api/eponyme-sitemap
```

```json
{
  "entries": [
    { "loc": "/articles/my-article", "lastmod": "2026-07-28T12:00:00.000Z" }
  ]
}
```

It includes singleton routes and the published entries of every collection configured in
`previewPaths`. Drafts, trashed entries and anything without a declared path are excluded. Each
collection is read in one query, never one query per entry, and only metadata is returned, never
the content.

The same data is available server-side, so a Nuxt sitemap integration does not need an internal HTTP
request:

```ts [server/routes/sitemap.xml.ts]
export default defineEventHandler(async (event) => {
  const entries = await getEponymeSitemapEntries()
  setHeader(event, 'content-type', 'application/xml')
  return `<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
${entries.map(entry => `  <url><loc>https://example.com${entry.loc}</loc></url>`).join('\n')}
</urlset>`
})
```

::note
Pagination and a sitemap index are not implemented yet, so a collection beyond 50,000 URLs would need
splitting.
::
